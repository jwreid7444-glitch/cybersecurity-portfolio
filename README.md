## NIST 800-30 Risk Assessment & Vulnerability Tracker

**Methodology:** NIST SP 800-30 | **Tool:** Microsoft Excel | **Year:** 2026

### Overview
A risk register assessing cybersecurity risks across 5 asset types in a simulated small-business environment. Each risk is scored by Likelihood × Impact (1–25 scale) with documented mitigations aligned to real-world controls.

### Files
| File | Description |
|------|-------------|
| `Risk_Assessment_Vulnerability_Tracker.xlsx` | Risk register spreadsheet — all 5 assessed risks, scoring, mitigations |
| `Risk_Register_Explainer.docx` | Plain-English guide to the project and methodology |
